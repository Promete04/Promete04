I'm interested in the hardware side of security: how cryptography runs on real devices and how embedded and networked systems are protected. Currently looking for internships in embedded security, network security or hardware engineering.

## What I'm working on

- **FrodoKEM on AMD Versal AI Edge** (B.Sc. thesis): accelerating a lattice-based post-quantum KEM on the Alinx VD100 with HLS, offloading the bottleneck to the FPGA fabric and benchmarking latency, throughput and energy against a software baseline.
- **Ubiquitous computing system**: sensors and actuators built around a Siemens ET 200S station with a PC soft-PLC.
- **CSLib**: formalising SHA-256 for an open-source library of verified computer science.

## Projects

- **Threshold Key Escrow for E2E Group Messaging**: encrypted group chat where the group key can only be recovered by 3 of 5 escrow authorities, and the server never sees keys or plaintext. Feldman DKG, threshold ElGamal with Chaum–Pedersen proofs, signed-DH channels, RSA-PSS, a threat model and 50+ tests.
- **[Homelab](https://github.com/Promete04/homelab)**: two-node Proxmox cluster with GPU passthrough, TrueNAS, ~15 LXC containers and 2 VMs. Remote access through Tailscale with ACLs, selected services exposed via Cloudflare Tunnel, documented in a public engineering log.
